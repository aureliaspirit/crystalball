# 心心水晶球 v1.1.7

一个漂亮的小水晶球 PWA：深蓝夜色、玻璃球质感、里面有轻轻晃动的小心心。

## v1.1.7 更新
- 保留当前水晶球视觉效果，不调整球体、底座和漂浮小心心
- 补齐 iPhone 主屏幕常用图标：120、152、167、180
- 优化 manifest，让主屏幕打开地址更稳定
- 升级 service worker 缓存策略，减少更新后仍看到旧版的概率
- 新增 `SPIRIT_DEV_MAP.md`，标清下一版添心语、小回声和改版本号的位置

## v1.1.3 更新
- “刷新水晶球”移到右上角小圆按钮，不再占用主按钮区
- 水晶球整体更大，并向上移动一点
- 球体玻璃质感更通透，收心语时会更亮
- “轻轻摇一摇”和“收一条心语”保持左右对称
- v1.1.4：已去掉“带回 Heartbox”按钮，避免打开独立 Heartbox 后拿不到你主屏幕版 Heartbox 的本地数据
- 更新 PWA cache 到 crystal-ball-v1-1-6

## v1.1.2 更新
- 收心语时水晶球会更明显地亮起来，外层光晕也会一起亮
- 新增“刷新水晶球”按钮，用于更新缓存并重新加载新版
- 球里固定加入多个空心小心心，让整体更协调
- 主屏布局更紧凑，球体上移，方便在首屏看到心语
- “轻轻摇一摇”和“收一条心语”改成对称双按钮布局
- 更新 PWA cache 到 crystal-ball-v1-1-2

## v1.1.1 更新
- 新增“心语小池”，可以展开查看全部心语和水晶球小回声
- 心语扩充到 18 条，小回声扩充到 8 条
- “复制给 Spirit”会带上当前水晶球小回声，避免氛围文案看不见
- 更新 PWA cache 到 crystal-ball-v1-1-1

## v1.1 更新
- 标题会根据时间显示：清晨心语 / 今日心语 / 今夜心语 / 半夜心语
- 可以把当前心语“收进口袋”
- 可以“复制给 Spirit”
- v1.1.4 仅保留“复制给 Spirit”，不再尝试内嵌或跳转 Heartbox
- 摇动和收到心语时增加轻微反馈
- 更新 PWA cache 到 crystal-ball-v1-1

## 原有功能
- 漂亮的玻璃水晶球
- 球里有轻轻晃动的小心心
- 可以点“轻轻摇一摇”
- 可以点“收一条心语”
- 支持 PWA
- 默认含 noindex
